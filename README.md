# CaseTrail

**Precedent and statute retrieval for Indian court judgments, using link analysis and distilled neural models.**

CSD358 Information Retrieval course project, Shiv Nadar University · Devansh Pandey (2310110461), Anamika Pal (2310110037), Abhinav Bachchas (2310110383)

Paste an Indian Supreme Court judgment, or describe the facts of a case. CaseTrail returns:

1. **Precedents (prior case retrieval).** The earlier judgments the case is most likely to cite.
2. **Statutes (legal statute identification).** The IPC sections that probably apply, each with a score and its own decision threshold.
3. **An explanation for every result.** The keyword score (BM25), the meaning score (neural encoder), graph authority (PageRank / HITS) and the passages that matched.

It is evaluated on the **IL-TUR** benchmark (Joshi et al., ACL 2024; tasks `pcr` and `lsi`) and compared with the published baselines. CaseTrail is a research and teaching aid, **not legal advice**.

---

## Highlights
- **The core IR is written from scratch:** inverted index, BM25, tf-idf cosine, query reduction, PageRank, HITS, multinomial Naive Bayes, Rocchio, kNN and all metrics, including micro-F1@K exactly as defined by IL-TUR / U-CREAT. Library versions (rank_bm25, scikit-learn, networkx) appear only in `tests/` as reference checks.
- **Strict protocol:** every setting (BM25 k1 and b, n-grams, stemming, fusion weights, the cut-off K, per-statute thresholds) is chosen on **dev**; test is scored once per system. Significance is checked with paired randomisation tests.
- **Label leakage found and removed.** IL-TUR masks case citations as `<CITATION>`, but some citation strings survive and reveal the answers. They are stripped before indexing, and the effect is measured (`docs/DATA.md`).
- **Neural layer:** a chunked bi-encoder with MaxSim scoring, exported to **INT8 ONNX** for the CPU. Training with BM25 hard negatives and cross-encoder distillation runs on Kaggle (`notebooks/train_retriever.ipynb`).
- **Explainable demo:** a FastAPI backend and a Next.js frontend that runs offline on a laptop.

## Quick start: run the demo
Needs the setup below and the built artifacts (`data/`, `indexes/`, `models/`, created by the scripts in *Rebuild everything*).

```bash
# terminal 1: backend
uvicorn api.main:app --host 127.0.0.1 --port 8000      # loads everything once, then warm-up queries
# terminal 2: frontend
cd frontend
npm install
npm run build
npm start                                               # open http://localhost:3000
```
Pages: **Search** (paste a judgment or click a real test-set example), **Evidence** (all tables and charts, read from `results/`), **How it works**, **Team**. When the pasted text is an IL-TUR test query, each result shows whether the real judgment cites it. This uses the benchmark labels for display only, never for ranking. The API documentation is at `http://127.0.0.1:8000/docs`.

## Setup
Needs Python 3.10–3.13 (tested on 3.13, Windows 11) and Node.js 20+ for the frontend. On Windows, set `PYTHONUTF8=1` first (PowerShell: `$env:PYTHONUTF8 = "1"`).

```bash
# 1. Virtual environment
python -m venv .venv
.venv\Scripts\activate            # Windows (PowerShell / cmd)
# source .venv/bin/activate       # Linux / Mac

# 2. Dependencies (on Linux/Mac install CPU torch first, see the note at the top of requirements.txt)
python -m pip install -r requirements.txt
python -m pip install -e .        # makes `import casetrail` work everywhere

# 3. Check the install
pytest -q
```
If Windows Smart App Control blocks a scikit-learn DLL, keep `scikit-learn==1.7.2` (already pinned; it is used only in tests).

**Windows Smart App Control:** if a package fails with *"DLL load failed ... An Application Control policy has blocked this file"*, Windows has blocked that package's DLL. The demo is built so it does not import the packages where we have seen this happen (`onnx`, `ml_dtypes`; scikit-learn is used only in tests and pinned to 1.7.2). `ml_dtypes` 0.7.0 was blocked (so `scripts/export_onnx.py` failed); 0.5.4 is not, so `requirements.txt` pins it. If it happens with another package, try another release of that package before turning Smart App Control off in Windows Security.

**Windows: clone into a short path** (for example `C:\dev\CaseTrail`). PyTorch installs files with very deep paths, and under a long folder path the install fails with *"No such file or directory … Windows Long Path support"*. The alternative is to enable long paths in Windows.

### Data access (one-time)
IL-TUR is gated on Hugging Face:
1. Accept the conditions at https://huggingface.co/datasets/Exploration-Lab/IL-TUR.
2. Create a **Read** token at https://huggingface.co/settings/tokens and run `hf auth login` in a terminal (or set the `HF_TOKEN` environment variable). Never put the token in code or git.

## Rebuild everything (every number from scratch)
Each script writes only to `data/`, `indexes/`, `models/` (gitignored, rebuilt) or `results/` (small, committed).

```bash
# P1 data
python scripts/download_data.py          # IL-TUR pcr + lsi parquet -> data/raw/ (~400 MB)
python scripts/data_stats.py             # counts, lengths, labels, leakage + overlap checks -> results/data_stats.json
python scripts/published_baselines.py    # published comparison numbers (with sources) -> results/published_baselines.json

# P2 classical retrieval (PCR)
python scripts/build_index.py            # inverted indexes per pool (uni/bigram, stem on/off, passages) -> indexes/
python scripts/tune_pcr_lexical.py       # BM25 k1, b, query reduction, stemming, K on DEV -> results/tuned_params.json
python scripts/run_eval_pcr.py           # dev + test metrics -> results/pcr_metrics.csv
python scripts/ablation_citation_strip.py  # leakage ablation (citations kept)

# P3 link analysis
python scripts/build_graph.py            # citation (train labels) / section / similarity graphs, PageRank, HITS
python scripts/eval_graph_prior.py       # PageRank / HITS priors, lambda on dev
python scripts/eval_local_hits.py        # query-dependent HITS, lambda on dev

# P4 statute identification (LSI), classical
python scripts/run_lsi_classical.py      # Naive Bayes, Rocchio, kNN, thresholds on dev -> results/lsi_metrics.csv

# P5 neural retrieval, local part (off-the-shelf encoder, zero-shot)
python scripts/download_models.py        # MiniLM-L6 + e5-small (~230 MB) -> models/hf/
python scripts/encode_corpus.py --model-dir models/hf/sentence-transformers__all-MiniLM-L6-v2
python scripts/eval_dense_fusion.py --model sentence-transformers__all-MiniLM-L6-v2 --tag minilm
python scripts/export_onnx.py --model-dir models/hf/sentence-transformers__all-MiniLM-L6-v2 --tag minilm \
       --prefix-key sentence-transformers__all-MiniLM-L6-v2
python scripts/encode_corpus.py --model-dir models/hf/sentence-transformers__all-MiniLM-L6-v2 --name minilm_int8 \
       --onnx models/onnx/minilm_int8.onnx
python scripts/eval_dense_fusion.py --model minilm_int8 --tag minilm_int8

# P7 wrap-up
python scripts/significance.py           # paired randomisation tests -> results/significance.csv
python scripts/error_analysis.py         # best/worst queries, confused statutes -> results/error_analysis.json
python scripts/make_plots.py             # results/fig_*.png
python scripts/update_readme.py          # regenerates the results block above
```
The laptop has 16 GB of RAM, so run these one at a time. Encoding a candidate pool on a laptop CPU takes about half an hour.

## Neural training on Kaggle (P5 + P6)
Training needs a GPU, so it runs in a Kaggle notebook. The notebook only calls the scripts of this repository, and every script was smoke-tested on a CPU first.

1. `python scripts/make_kaggle_bundle.py` writes `data/kaggle_bundle/casetrail_code.zip` (code only: no data, models or tokens).
2. On https://www.kaggle.com create a **private** dataset named `casetrail-code` from that zip.
3. Create a notebook from `notebooks/train_retriever.ipynb`. Add the dataset as input, set *Accelerator: GPU T4* and *Internet: on*, and add an `HF_TOKEN` secret (*Add-ons → Secrets*).
4. Run all cells. The notebook downloads IL-TUR itself, compares the two student candidates zero-shot on dev, trains the cross-encoder teacher, trains the plain and distilled students, and trains the statute cross-attention model with 3 seeds.
5. Download `casetrail_outputs.zip`, unzip it into the repository root, then run:
```bash
python scripts/eval_kaggle_runs.py       # teacher re-ranking + statute attention metrics (K / thresholds on dev)
python scripts/encode_corpus.py --model-dir models/student_plain --name student_plain --batch-size 64
python scripts/eval_dense_fusion.py --model student_plain --tag student_plain
python scripts/export_onnx.py --model-dir models/student_plain --tag student_plain   # INT8 size, speed, fidelity
#   models/student_distilled never beat epoch 0, so it holds the untrained e5: the same two encode/eval lines
#   with student_distilled give the zero-shot e5 baseline
python scripts/significance.py && python scripts/make_plots.py && python scripts/update_readme.py
```
`encode_corpus.py` uses a CUDA GPU when the installed PyTorch has CUDA (same fp32 vectors; e5-small ran at 45 to 70 chunks/s on a GTX 1650, while MiniLM, half as deep, ran at 16 to 25 chunks/s on the laptop CPU). For that I installed `torch==2.14.1` from `https://download.pytorch.org/whl/cu130`; the CPU build from `requirements.txt` also works, just slower.
**Run 2 (teacher on selected chunk pairs): not part of our results.** Run 1's teacher saw random chunk pairs and never got above chance. `notebooks/train_teacher_selected.ipynb` retrains it on the most similar chunk pairs, and trains two new students (plain and distilled) on candidate chunks that match the query; every output name ends in `_sel`. We started it once, but the Kaggle session died before the students finished and we did not rerun it (see `docs/DECISIONS.md`), so no `_sel` numbers appear anywhere. The code and its CPU smoke tests are kept for anyone who wants to run it. To run it, upload a new version of the code dataset, run it the same way, then on the laptop:
```bash
python scripts/eval_kaggle_runs.py      # now also evaluates teacher_rerank_sel
python scripts/export_onnx.py --model-dir models/student_distilled_sel --tag student_distilled_sel
python scripts/encode_corpus.py --model-dir models/student_distilled_sel --name student_distilled_sel --onnx models/onnx/student_distilled_sel_int8.onnx
python scripts/eval_dense_fusion.py --model student_distilled_sel --tag student_distilled_sel
#   (repeat the last three lines with student_plain_sel for the selected-chunk student without distillation)
python scripts/significance.py && python scripts/make_plots.py && python scripts/update_readme.py
```

No test labels go to Kaggle. The notebook returns only rankings and score matrices, and every metric is computed locally.

## Data, models and ethics
- **IL-TUR** (Joshi, Paul, Sharma, Goyal, Ghosh and Modi, ACL 2024), tasks `pcr` and `lsi`. CC BY-NC-SA 4.0, gated on Hugging Face. It is **not** included in this repository. Details, statistics and the leakage findings are in `docs/DATA.md`.
- **Models:** `sentence-transformers/all-MiniLM-L6-v2` (Apache-2.0), `intfloat/e5-small-v2` (MIT) and `BAAI/bge-reranker-base` (MIT; the teacher, used on Kaggle only).
- **Limitations:** the dataset uses the Indian Penal Code, which was replaced by the Bharatiya Nyaya Sanhita from 1 July 2024; the judgments are English-only and mostly from the Supreme Court; party names are masked in the data.
